# DIAL Premium Cinematic Web Standard

## Governing rule
Cinematic treatment serves product understanding. It never overrides product truth, workflow clarity, safety, accessibility or performance.

## Design zones
| Zone | Surfaces | Max intensity |
|---|---|---|
| A | brand, homepage, acquisition, enterprise/investor | HIGH |
| B | marketplace discovery, service/technician browse/profile | MEDIUM |
| C | booking, quote, checkout, payment | LOW |
| D | HIRA/PPE/LOTO/SOP/job execution/admin | MINIMAL |

## Experience modes
CINEMATIC-SCROLL, CINEMATIC-VIDEO, TRUE 3D/WEBGL, INTERACTIVE-MOTION, PRODUCT-UI, STATIC-CONTENT.

## Required sequence
`Product Truth → Product Story Architecture → Blueprint-to-Experience map → reference research → CDB → CEM → storyboard → asset plan → approved media → implementation → performance/accessibility/mobile/reduced-motion/visual QA`

## Product Story Architecture
Define audience, value proposition, trust/safety model, marketplace/technical differentiators, CTA hierarchy, and what needs demonstration, explanation, cinema or simple UI.

## Awwwards/reference research
Research current premium references for scroll/image sequences/marketplace/product storytelling/WebGL/motion/navigation/type/mobile. Record `what works → why → technique → narrative problem → DIAL lesson → what not to copy`.

## Cinematic Design Brief
Purpose/audience/narrative/visual world/color/type/motion/image/cinematography/signature technique/sections/interactions/mobile/performance/accessibility.

Generate materially different visual directions before committing.

## Asset-first workflow
`CDB → storyboard → still/keyframes → approval → video/sequence → QA → optimization → implementation`.

User-selected preferred media workflow:
- Higgsfield MCP where a current official connector is available/authorized;
- Seedance 2.0 for cinematic video where available;
- Nano Banana Pro for still/keyframe generation where available.

These are design-time tools, not runtime product dependencies.

## Scroll sequences
`approved video → frames → cleanup → WebP/AVIF → manifest → preloader → canvas → scroll progress → frame index`.
Use GSAP ScrollTrigger or compatible equivalent. Use Lenis only when justified.

## 3D justification
WebGL only when viewpoint/spatial relation/object exploration/material-light behavior materially improves understanding and pre-rendered media is insufficient.

## Real UI
Never replace search/profile/booking/quotes/job/messaging/payment/safety/dashboard interfaces with cinematic video.

## Performance
Minimum LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1. Set budgets for JS, images, sequences, video, WebGL memory and initial payload. Do not preload an entire cinematic site.

## Progressive enhancement
Semantic content → CSS → light motion → cinematic sequences → WebGL. Higher layers may fail without destroying core usability.

## Mobile
Choose per section: same / reduced sequence / video substitute / still+overlay / conventional layout / disable 3D. Design for portrait, bandwidth, memory, thermal limits, touch and viewport height.

## Reduced motion
Static poster/simple fade/equivalent text/same CTA/navigation. No important meaning only in motion.

## Accessibility
Semantic HTML/headings/keyboard/focus/contrast/alt text/forms/zoom/reduced motion. Canvas/WebGL is never semantic content.

## Maintainability
Separate content, tokens, motion config, generated media, scroll logic, WebGL and real product UI.

## Verification
Minimum three serious visual refinement passes: build → screenshot sweep → desktop → mobile → motion → issues → fix → repeat.

Generated media QA must catch malformed equipment, unsafe practice, incorrect PPE, impossible tools, inconsistent people, unwanted text/branding and invented capabilities.

## Authenticity
Every substantive product claim and depicted capability traces to Project Truth.

## SEO
Crawlable content, metadata, canonical URLs, semantic HTML, sitemap, structured data/social metadata as applicable.

## Records
PSA, CDB, CEM, ASR, APM, EDR, Performance Budget, Mobile Strategy, Reduced-Motion Strategy.
