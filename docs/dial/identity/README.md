# DIAL Identity / Brand Pack

This directory contains the DIAL Brand Pack authority package.

## Human specifications

- `DIAL_BRAND_PACK_REV1.md` — Project-Truth-aware identity and product-expression standard.
- `DIAL_BRAND_PORTAL_REV1.md` — product specification for the human/machine-facing Brand Portal.

## Machine-readable source

- `brand-pack/DIAL_BRAND_PACK_MANIFEST.v1.json` — Brand Pack release manifest, product-expression profiles and identity intelligence.
- `brand-pack/DIAL_BRAND_STAGE_PROJECTION_POLICY.v1.json` — stage-aware projection contract for feeding the existing development system.

## Authority boundary

These artifacts enrich the existing DIAL frontend system. They do not replace or duplicate:

- Project Truth;
- Feature/FRC/domain authority;
- Screen Registry × Feature Graph;
- VEKL;
- Product Experience / FDEP;
- frontend token/component/pattern registries;
- Stitch provider policy;
- Visual Authority;
- Experience Authority;
- DDE productionization/certification.

The Brand Pack must be projected **after canonical product/application/screen resolution** and before design-provider generation when applicable.

The key identity law is:

> **White creates space. Black creates structure. Orange creates attention.**

The key integration law is:

> **Brand intelligence enriches design; it does not seize product or development authority.**
