# DIAL Home — Landing Page Donor Selection

## Locked choice

**Primary code/UX donor:** `nobruf/shadcn-landing-page`  
**Adoption:** `PORT-SELECTED-MODULE + PORT-UX-UI`  
**Licence:** MIT

Why it fits DIAL:
- Next.js + TypeScript + Tailwind + shadcn-style components;
- responsive mobile navigation;
- hero, services, benefits, FAQ and footer sections;
- clean modern visual language;
- service-oriented rather than ecommerce-only;
- easy to transplant into DIAL's existing Next.js/shadcn stack.

Repository:
`https://github.com/nobruf/shadcn-landing-page`

## Port

- navbar/mobile menu;
- hero composition;
- services section;
- benefit/trust patterns;
- FAQ;
- footer;
- useful responsive composition.

## Replace

- donor branding/copy;
- generic SaaS pricing/team/community content;
- donor colors/type/spacing;
- donor routing;
- any auth-first CTA hierarchy.

## Add

- DIAL Service Router;
- universal intent/search box;
- signed-in Continue/Activity strip;
- location/availability context;
- DIAL Business entry;
- Dial Health entry;
- Help/Support;
- Continue on WhatsApp;
- DIAL design system;
- SEO and performance budgets;
- accessibility/data saver/reduced motion.

## Secondary visual reference

Cruip Simple Light can be used as a visual-quality reference, but its source is GPL and should not be copied into DIAL unless GPL obligations are deliberately accepted.

## Objective

The home should feel like a trusted national service network, not an auth page, ERP dashboard, ecommerce store or generic SaaS page.

Its main question is:

**What do you need DIAL to do for you today?**
