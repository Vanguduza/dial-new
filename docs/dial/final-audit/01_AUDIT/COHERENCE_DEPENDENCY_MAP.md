# Coherence Dependency Map

```text
Identity / Party / Organisation
       │
Catalogue / Vehicle / Fitment
       │
Pricing / Promotions
       │
Orders / Jobs / Projects
       │
Payments → Ledger → Tax/FX
       │
Delivery
       │
Evidence → Quality → RCE → Claims
       │
Customer 360 / Engagement
       │
Network / Provider Quality / Trust
       │
Command Centre
       │
AI / Simulation
```

Branches converge onto shared engines rather than cloning them. Groceries and Laundry extend fulfilment/custody semantics but do not create second money/delivery/identity systems. Fleet/Hub/Care/Assist reuse vehicle/jobs/delivery/money history. Corporate Management reuses Identity/Ledger/Evidence/Workflow rather than becoming a foreign ERP.
