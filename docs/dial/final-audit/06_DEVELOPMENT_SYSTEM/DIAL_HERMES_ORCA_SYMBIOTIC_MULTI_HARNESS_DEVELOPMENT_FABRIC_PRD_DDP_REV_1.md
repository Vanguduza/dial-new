# 00. EXECUTIVE CONTRACT

DIAL SHALL operate one coherent development system in which:

```text
Owner Intent
   ↓
Project Truth / PRD / Development Pack
   ↓
Deterministic Development Stage Graph
   ↓
Hermes Orchestration Authority
   ↓
Manager Cognitive Runtime
   ↓
VEKL Knowledge Resolution
   ↓
AEF / HCX Task Routing
   ↓
Compute + Lease/Fencing Admission
   ↓
Orca Persistent Workspace / Worktree / Session
   ↓
Qualified Coding Harness
   ↓
Tests / Specialists / Review / Evidence
   ↓
Gate Reconciliation
   ↓
SPMRF Shared Persistent Memory
   ↓
OpenViking Semantic Projection
   ↓
VAN Owner Control / TODO / Evidence
```

The defining rules are:

1. **Hermes remains the single normal orchestration authority.**
2. **Orca is a subordinate execution/workspace plane, not an orchestrator of record.**
3. **Product Truth and the project Development Pack define what should be built.**
4. **VEKL determines admitted engineering knowledge; tools and models cannot invent authority.**
5. **HCX selects eligible workers; Orca materializes their workspaces.**
6. **All repository-writing work is bound to Task Execution Envelopes, leases and fencing.**
7. **Every model/harness shares one external persistent project-memory fabric.**
8. **OpenViking is integrated into that existing memory architecture as a subordinate semantic projection.**
9. **VAN displays the exact canonical development plan and live work graph rather than a separate mobile task list.**
10. **Agent self-report never equals completion. Completion is evidence-backed admission.**
