---
name: dial-feature-realize
description: Convert a DIAL Feature ID/FRC into a bounded implementation changeset with evidence. Use for material feature work.
---
1. Run `node agent-system/bin/context-get.mjs <FEATURE_ID>`.
2. Verify actual repository state; planning is not implementation evidence.
3. Resolve FRC owner/state/data/API/events/permissions/eventualities/tests.
4. Plan and implement one coherent changeset.
5. Run domain/static/security checks.
6. Use a fresh evaluator for material work.
7. Record evidence before changing status.
