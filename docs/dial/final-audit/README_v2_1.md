# DIAL Consolidated Development Pack v2.1

This is the single active consolidation pack for the next DIAL development phase.

## What changed from v2.0

- Shop-Ecommerce is now the primary customer-facing frontend donor for Dial a Spare and Dial Groceries.
- Mercur is retained for marketplace/supplier architecture rather than as the primary public visual frontend.
- Nimara / Your Next Store remain polish references.
- Spares Shop and Car Zone become automotive visual/merchandising references.
- Car_e-commerce remains a functional automotive donor.
- SandPIM + ACESinspector + ACESlint provide fitment/catalogue intelligence.
- the user-supplied Catalog Agent and Vehicle-to-EPC integration documents are bundled verbatim and promoted as frozen specialist contracts.
- the Master Development Plan and Master Development Prompt are updated to bind the commerce frontend to those contracts.
